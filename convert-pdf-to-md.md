# How to Convert PDF to Markdown

## Option 1: Using Pandoc (Recommended)

1. Install Pandoc:
   - Download from: https://pandoc.org/installing.html
   - Or use Chocolatey: `choco install pandoc`

2. Convert the PDF:
   ```bash
   pandoc src/assets/resume/cv.pdf -o cv.md
   ```

## Option 2: Manual Copy-Paste

1. Open `src/assets/resume/cv.pdf` in a PDF viewer
2. Copy all the text
3. Paste it here and I'll format it as markdown

## Option 3: Online Tools

Use an online PDF to Markdown converter:
- https://www.zamzar.com/convert/pdf-to-md/
- https://cloudconvert.com/pdf-to-md
